# Quake2GoSharp

Quake2GoSharp is a C# / Windows Forms / OpenTK Quake II PAK and BSP viewer.

It can load a Quake II `pak0.pak`, list the maps contained in the archive, render BSP maps, navigate them in FPS/free-roam modes, and includes lightweight viewer features such as a crosshair, blaster effect, sound effects, background music, and player movement sounds.

## Credits
